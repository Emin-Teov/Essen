# Essen

A third-person, open-world 3D shinobi game for mobile, written in Flutter.
You play **Essen**, a ninja of the Hidden Mist village, fighting the samurai of the Iron Dragon clan in feudal Japan.

- **Languages:** English, Azərbaycanca and 日本語. Pick one on the title screen; the default follows the device language.
- **Story:** see [STORY.md](STORY.md).
- **Developer and AI notes:** see [ai-knowledge/](ai-knowledge/README.md).

## Running

```sh
flutter pub get
flutter run                                  # Android/iOS device, landscape
flutter test test/                           # tests
flutter test tool/generate_icons_test.dart   # regenerate icons + launcher icons
dart run tool/generate_effects.dart          # regenerate 3D effect models (assets/effects/*.obj + .mtl)
```

The game also runs on desktop (`flutter run -d windows`) for keyboard testing.

## Controls

| Touch | Keyboard | Action |
|---|---|---|
| Drag on the left side | WASD (+Shift to run) | Move relative to the camera. Push the stick to its edge to run |
| Drag on the right side | Arrow keys | Orbit the camera around Essen |
| Slash button (hold for combos) | J / F | Katana. Turns toward the nearest foe in front |
| Shuriken button | K / E | Thrown where the camera aims, with light aim assist |
| Jump button | Space | Jump. Tap again in the air to double-jump |
| Crouch button | C | Stealth: half detection range |
| Smoke button | Q | Blinds nearby enemies and hides you |
| Pause button | Esc | Pause / codex |

Strike an enemy who hasn't noticed you, or who is blinded, for an instant **Shadow Strike**.

## Architecture (short)
There are no game-engine dependencies. A custom 3D renderer draws everything with `Canvas.drawVertices`. All in-world effects (slash arcs, impact flashes, shockwave rings, fire, smoke, dust, sparks, alert markers, the objective beacon, projectiles, pickups) are **Wavefront OBJ/MTL models** in `assets/effects/`, which open in Blender or any 3D viewer.
Icons and launcher icons are generated by code.
Details are in [ai-knowledge/architecture.md](ai-knowledge/architecture.md).

```
lib/engine   math, noise, meshes/lighting, renderer + sky
lib/game     terrain, world, props, characters, player, enemy AI, effects, game loop
lib/story    chapter/objective structure
lib/l10n     all text: UI strings + story in EN / AZ / JA
lib/ui       screens, HUD, touch controls, icons, saved progress
tool/        icon generator
```
