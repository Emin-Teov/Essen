# Essen — notes for AI assistants

Read `ai-knowledge/README.md` first. It indexes the architecture, conventions (two yaw conventions!), rendering, gameplay, story, localization, icons, testing, gotchas and recipes.

Ground rules:
- `flutter analyze` must be clean and `flutter test test/` must pass before you finish.
- Player-facing text goes through `lib/l10n/` in **all three languages** (EN/AZ/JA). Use `upper()`, never `toUpperCase()`, in UI.
- Icons are generated by `flutter test tool/generate_icons_test.dart`. 3D effect models (OBJ/MTL) can be generated by `dart run tool/generate_effects.dart` (this overwrites them) or hand-edited; after editing run `dart run tool/validate_effects.dart`.
- Keep `STORY.md` in sync with story changes.
