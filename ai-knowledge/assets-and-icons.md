# Assets and icons

All icons are **generated by code** in `tool/generate_icons_test.dart`. No external image tools are needed.

```sh
flutter test tool/generate_icons_test.dart
```

It writes:
- `assets/icons/{slash,shuriken,jump,smoke,crouch,pause}.png` at 192 px, transparent: the HUD buttons.
- `assets/icons/flag_{en,az,ja}.png` at 144 × 96: the language picker and the title-screen button.
- `assets/icons/app_icon.png` at 512 px: the master app icon.
- **Launcher icons:** every existing PNG under
  - `android/app/src/main/res/mipmap-*`
  - `ios/Runner/Assets.xcassets/AppIcon.appiconset`
  - `macos/Runner/Assets.xcassets/AppIcon.appiconset`
  - `web/icons` and `web/favicon.png`

  Each is re-rendered at its existing pixel size, which it reads from the PNG header. Maskable web icons keep the art inside an 80% safe zone. iOS icons are fully opaque, as the App Store requires.

## Runtime use
- `pubspec.yaml` declares `assets/icons/`.
- `GameIcons.load()` (ui/game_icons.dart) decodes the HUD icons into `ui.Image`s. `GameScreen` awaits it together with the world. `HudPainter` draws them with `drawImageRect` and falls back to a letter if an icon is missing.
- Flags are shown with `Image.asset(GameIcons.flagAsset(lang.name))`.

## Adding an icon
1. Write a painter function `void _myIcon(Canvas c, Size s)` in the generator.
   - Design on a 192-unit grid: `k = s.width / 192`.
   - Use `_glyph(c, s, path, paint)` for a consistent drop shadow and dark outline.
2. Add it to the `icons` map in the generator.
3. If the HUD should load it, add the name to `GameIcons.names`.
4. Run the generator, then look at the PNG (an AI assistant can open it with its image-reading tool).
